# 漫剧工坊 AI

这是一个轻量级的 AI 漫剧生成器前端原型，适合在本地开发和预览。用户可以输入故事主题、情绪、风格和角色信息，应用会自动生成故事概述、角色卡和分镜脚本。

## 启动方式

```bash
npm install
npm run dev
```

然后在浏览器中访问：

```text
http://localhost:5173
```

## 功能

- 输入故事主题和风格
- 自动生成剧本摘要
- 生成角色设定卡
- 自动拆分分镜脚本
- 每个镜头生成画面提示词
- 支持在前端实时预览

## 技术栈

- React
- Vite
- CSS

## 说明

当前版本是前端原型，生成内容为本地模拟数据，不接真实 AI API。后续可以继续接入 LLM、图像生成、配音和视频渲染能力。
